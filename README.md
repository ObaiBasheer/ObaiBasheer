# 🎯 Engineering Philosophy

I care less about making something simply **work** and more about understanding:

* What happens when it fails?
* Can we retry safely?
* Is the operation idempotent?
* What happens when the network disappears halfway through?
* Can we observe what went wrong?
* Can another engineer understand and maintain it?
* Will the architecture still make sense when the system grows?

That's the kind of engineering I'm trying to get better at.
